# 欢迎学习 Talent Plan 课程！

![Talent Plan Logo](media/talent-plan-logo.png)

Talent Plan 是由 PingCAP 发起的开源培训计划。该计划旨在为对开源、分布式系统、Rust、Golang 及其他基础设施知识感兴趣的人创建或整合开源学习材料。因此，它提供了一系列专注于开源协作、Rust 编程、分布式数据库和系统的课程。

> 注意：

> 每个课程由不同团队开发，因此其组织结构和学习成果可能有所不同。详情请参见各课程的文档。

## 我们的课程

### 系列1：开源协作

开源协作包含一系列与开源相关的学习材料，帮助爱好者了解开源软件的基本概念、现有开源软件许可证之间的差异、如何参与开源项目，以及一个友好的开源社区是什么样子。

课程包括：

- [TP 101：开源软件入门](courses/tp101-intro-to-oss.md)
- [TP 102：如何使用 Git 和 GitHub](courses/tp102-how-to-use-git-github.md)
- [TP 103：构建友好社区](courses/tp103-open-source-community.md)

### 系列2：Rust 编程

本系列是 Talent Plan 的核心内容，旨在帮助您深入理解 Rust 编程语言，并提供实践机会。

课程包括：

- [TP 201：Rust 中的实用网络应用](courses/rust/README.md)。一系列项目逐步将单个 Rust 项目从零构建为高性能、网络化、并行和异步的键值存储。过程中探讨和讨论各种现实世界的 Rust 开发主题。

- [TP 202：Rust 中的分布式系统](courses/dss/README.md)。本课程改编自 [MIT 6.824](http://nil.csail.mit.edu/6.824/2017/index.html) 分布式系统课程，重点在于实现重要的分布式算法，包括 [Raft](https://raft.github.io/) 共识算法和 [Percolator](https://storage.googleapis.com/pub-tools-public-publication-data/pdf/36726.pdf) 分布式事务协议。

### 系列3：分布式数据库

本系列介绍 TinySQL 和 TinyKV，这两个是用 Go 编写的分布式数据库。

课程包括：

- [TP 301：TinySQL，Go 编写的分布式关系型数据库](https://github.com/pingcap-incubator/tinysql)
- [TP 302：TinyKV，Go 编写的分布式键值数据库](https://github.com/pingcap-incubator/tinykv) 

### 系列4：深入 TiDB 生态系统

本系列介绍由 PingCAP 开发的分布式数据库 TiDB 和 TiKV。

课程包括：

- TP 401：深入 TiDB（开发中）
- TP 402：深入 TiKV（开发中）

更多详情请参见 [课程](courses/README.md)。
