# 路径 2：TiKV 方向

## 课程目标
* 掌握 Rust 语言
* 掌握分布式一致性算法 Raft
* 掌握分布式存储的基本原理

## 课程内容

### 第一节：熟悉 Rust 语言基础知识

**学习资料：**

* [Practical Networked Applications in Rust](https://github.com/pingcap/talent-plan/tree/master/courses/rust)
* 阅读《[Rust 编程之道](https://book.douban.com/subject/30418895/)》或《[深入浅出 Rust](https://book.douban.com/subject/30312231/)》或 [Rust 官方教程](https://doc.rust-lang.org/book/)，三者选其一

**课程作业：**

* 完成 [Practical Networked Applications in Rust](https://github.com/pingcap/talent-plan/tree/master/courses/rust) 中的 Project 1 和 Project 2（欢迎对本课程提出改进建议并协助优化，根据建议质量与改进情况可获得额外加分哦~）

### 第二节：熟悉 Rust 语言基础知识

**学习资料：**

* [Practical Networked Applications in Rust](https://github.com/pingcap/talent-plan/tree/master/courses/rust)
* 阅读《[Rust 编程之道](https://book.douban.com/subject/30418895/)》或《[深入浅出 Rust](https://book.douban.com/subject/30312231/)》或 [Rust 官方教程](https://doc.rust-lang.org/book/)，三者选其一

**课程作业：**

* 完成 [Practical Networked Applications in Rust](https://github.com/pingcap/talent-plan/tree/master/courses/rust) 中的 Project 3 和 Project 4（欢迎对本课程提出改进建议并协助优化，根据建议质量与改进情况可获得额外加分哦~）

### 第三节：分布式存储基础知识

**学习资料：**

* 学习 Raft 论文以及 [6.824 Lab 2: Raft](https://pdos.csail.mit.edu/6.824/labs/lab-raft.html) 在线课程

**课程作业：**

* 使用 Rust 语言完成 [6.824 Lab 2 Raft 作业](https://github.com/pingcap/talent-plan/tree/master/dss)

### 第四节：分布式系统基础知识

**学习资料：**

* 完成 [6.824 Lab 3: Fault-tolerant Key/Value Service](https://pdos.csail.mit.edu/6.824/labs/lab-kvraft.html) 在线课程

**课程作业：**

* 使用 Rust 语言完成 [6.824 Lab 3 kvraft 作业](https://github.com/pingcap/talent-plan/tree/master/dss)

### 第五节：阅读 TiKV 源码

**学习资料：**

* [TiKV 源码解析](https://pingcap.com/blog-cn/#TiKV-%E6%BA%90%E7%A0%81%E8%A7%A3%E6%9E%90)（持续更新中）

**课程作业：**

* 向 TiKV 仓库提交 PR，例如修复 [面向新手的 Issues](https://github.com/tikv/tikv/issues?q=is%3Aissue+is%3Aopen+label%3A%22D%3A+Easy%22+label%3A%22S%3A+HelpWanted%22)。
* 向 PD 仓库提交 PR，例如修复 [面向新手的 Issues](https://github.com/tikv/pd/issues?q=is%3Aissue+is%3Aopen+label%3A%22D%3A+Easy%22+label%3A%22S%3A+HelpWanted%22)。

## 考核方式

根据提交的代码是否能通过测试，评定为 Pass 或 Fail：

1. 代码能通过 PingCAP 提供的测试程序的 50% 以上  
   a. `make check`  
   b. `make test`

2. 代码风格：30%  
3. 文档质量：20%
