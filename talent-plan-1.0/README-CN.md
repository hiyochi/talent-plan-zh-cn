# 人才计划课程 1.0

人才计划 1.0 课程共提供两条学习路径供您选择，分别是：

* 面向分布式关系型数据库 SQL 层的 [TiDB 方向](1.0-lp-tidb.md)
* 面向分布式 Key-value 数据库存储层的 [TiKV 方向](1.0-lp-tikv.md)

正在学习人才计划 1.0 课程的学员可通过上述链接查看相应路径的课程详情。

> ***特别提醒：***
>
> 人才计划 2.0 课程已正式上线。相较于 1.0 版本，2.0 新增了使用 Go 语言全新设计的分布式关系型数据库 TinySQL 课程和分布式 Key-value 数据库 TinyKV 课程，并根据大家的兴趣爱好与知识背景，重新规划了 5 条推荐学习路径，具体如下：
>
> * 路径 1：[实现一个迷你版分布式关系型数据库](https://learn.pingcap.com/learner/talent-plan/implement-a-mini-distributed-relational-database)
> * 路径 2：[实现一个迷你版分布式 Key-value 数据库](https://learn.pingcap.com/learner/talent-plan/implement-a-mini-distributed-key-value-database)
> * 路径 3：[参与工业级开源分布式关系型数据库 TiDB 的开发实践](https://learn.pingcap.com/learner/talent-plan/become-a-tidb-contributor)
> * 路径 4：[参与工业级开源分布式 Key-value 数据库 TiKV 的开发实践](https://learn.pingcap.com/learner/talent-plan/become-a-tikv-contributor)
> * 路径 5：[Rust 编程原理与实践](https://learn.pingcap.com/learner/talent-plan/rust-programming)
>
> 您也可直接通过 [人才计划官网](https://learn.pingcap.com/learner/talent-plan) 开始学习人才计划 2.0 课程。
