# 路径 1：TiDB 方向

## 课程目标
* 掌握 Go 语言
* 掌握分布式计算基本原理
* 掌握数据库基础知识
* 掌握优化器和执行引擎基本原理

## 课程内容

### 第一节：熟悉 Go 语言基础知识

**学习资料：**

* 阅读许老师的书 [《Go 语言开发》](https://book.douban.com/subject/11577300/)
* [Go 官方教程](http://tour.golang.org/)
* [Effective Go](https://golang.org/doc/effective_go.html)
* [Profiling Go Programs](https://blog.golang.org/profiling-go-programs)

**课程作业：**

* 使用 Go 语言实现一个多路归并的归并排序（Merge Sort）：内存中有一个无序的 int64 数组，包含 16M 个整数。要求使用多个 goroutine 对该数组进行排序，使元素按从小到大顺序排列，且排序性能需优于单线程快速排序（Quick Sort）。
* 根据[框架](https://github.com/pingcap/talent-plan/tree/master/tidb/mergesort)完成程序，**必须成功运行测试程序，并使用 Go Profile 工具分析性能瓶颈。需提供文档、单元测试和性能瓶颈分析报告。**

### 第二节：分布式计算基础知识

**学习资料：**

* 学习并使用 Go 语言完成 [6.824 Lab 1: MapReduce](https://pdos.csail.mit.edu/6.824/labs/lab-1.html)

**课程作业：**

* 使用 Go 语言，基于提供的框架代码，采用 MapReduce + Shuffle 的方式完成以下任务：从一个包含大量 URL 的数据文件中，找出出现频率最高的前 10 个 URL 及其出现次数，尽可能充分利用多核 CPU 和内存资源。
* 根据[作业框架](https://github.com/pingcap/talent-plan/tree/master/tidb/mapreduce)完成作业，详细的任务要求、框架使用方法及评分标准请参阅框架中的 README 文件。

### 第三节：数据库基础知识

**学习资料：**

* 阅读并自学 [《数据库系统概念》](https://book.douban.com/subject/1929984/) 相关章节，或学习 [CMU 15-445](https://15445.courses.cs.cmu.edu/fall2018/schedule.html) 对应内容：
	* 第 3 章：SQL
	* 第 11 章：索引与散列
	* 第 12 章：查询处理
	* 第 13 章：查询优化
	* 第 14 章：事务
	* 第 15 章：并发控制
	* 第 18 章：并行数据库
	* 第 19 章：分布式数据库

**课程作业：**

* 对以下 SQL 查询语句：`select t1.a, count(*), avg(t1.b) from t1 left outer join t2 on t1.a=t2.a group by t1.a`，列出所有可能的逻辑执行计划（绘制 Plan 树），并分析表 t1 的数据分布对各逻辑执行计划性能的影响。绘制 Plan 树时可使用 [Graphviz 作图工具](http://www.webgraphviz.com)。例如，对于查询 `select * from t where a > 1`，一个可能的执行计划如下图所示：

### 第四节：SQL 优化器和执行引擎基本原理

**学习资料：**

* 学习 [CMU 15-721](https://15721.courses.cs.cmu.edu/spring2018/) 数据库课程，结合自学与在线视频教学：
	* Optimizer Implementation (Part I)
	* Optimizer Implementation (Part II)
	* Cost Models
	* Execution & Scheduling
	* Vectorized Execution (Part I)
	* Vectorized Execution (Part II)
	* Parallel Join Algorithms (Hashing)
	* Parallel Join Algorithms (Sorting)

**课程作业：**

* 使用 Go 语言实现一个 Join 算法：从两个 CSV 文件中读取数据，在一个或多个等值条件上执行连接操作，并对最终结果求和。请参考 [README](https://github.com/pingcap/talent-plan/tree/master/tidb/join)，使用提供的框架完成作业并运行测试程序。提交的作业需代码整洁规范，附有完整文档，并提供对程序性能瓶颈的分析及优化建议。

### 第五节：阅读 TiDB 源码

**学习资料：**

* [TiDB 源码阅读 24 章经](https://pingcap.com/blog-cn/#TiDB-%E6%BA%90%E7%A0%81%E9%98%85%E8%AF%BB)

**课程作业：**

* 向 TiDB 仓库提交 PR，例如修复 [面向新手的 issue](https://github.com/pingcap/tidb/issues?utf8=%E2%9C%93&q=is%3Aissue+is%3Aopen+label%3A%22for+new+contributors%22+)。

## 考核要点

完成所有作业，代码通过邮件发送至 ts-team@pingcap.com。要求使用 Golang 1.12，提交内容必须包含代码、测试用例、注释和文档。

我们将依据以下评分标准进行评估，最终得出 0~100 分的总分：

1. 代码能成功通过 PingCAP 提供的测试程序（部分题目有性能要求，需在规定时间内完成）—— 50%  
2. 单元测试覆盖率 —— 30%  
3. [代码风格](https://github.com/pingcap/community/blob/master/CONTRIBUTING.md#code-style) —— 10%  
4. 文档完整性 —— 10%
