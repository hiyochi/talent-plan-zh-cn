# 2021 年人才挑战计划

人才挑战计划是一个为**大学生**提供的结构化远程导师计划平台，面向已完成人才计划课程或对 TiDB 项目做出贡献的学生。与 TiDB 生态系统相关的开源项目将与专业导师共同选定。学生可逐个申请项目，并在指定时间内在导师的指导下完成项目。通过与导师紧密合作，学员将获得真实的项目经验。成功完成项目的学生将获得**奖金及更好的就业机会**。

### 当前周期

2021 年人才挑战计划正在进行中，请查阅 [专属页面](schedule.md) 了解时间安排及可申请的项目。

## 沟通渠道

如有关于人才挑战计划的任何问题或建议，请随时在 [tidbcommunity](https://slack.tidb.io/invite?team=tidb-community&channel=talent-challenge-&ref=github/talent-plan) Slack 工作区的 **#talent-challenge** 频道联系我们。

## 如何参与

您可以根据自身角色参与人才挑战计划。该计划支持以下角色：

### 项目维护者/导师

项目维护者或导师需通过 [项目创意](project-ideas.md) 页面，使用 [模板](PROJECT_IDEA_TEMPLATE.md) 提交与 **TiDB 生态系统** 相关的项目建议。

TiDB 社区的项目管理委员会（PMC）将从中遴选参与本轮人才挑战计划的项目，入选项目将展示在 [入选项目](selected-projects.md) 页面。

*注意：*

- *入选项目必须至少配备一名导师。*
- *导师需准备好投入时间，协助学员完成项目。*

### 学员（Mentees）

*注意：*

- 必须为在校大学生。
- **已完成人才计划课程或对 TiDB 项目做出贡献的学生** 优先鼓励申请，或具备分布式数据库开发能力者。
- 每个周期内，每位学员仅可申请一个项目。

**在申请开放前，建议学员主动与导师沟通项目内容。** 这有助于学员完善想法，加深对项目的理解。

#### 学员选拔流程

1. 意愿参与人才挑战计划的学员需加入 Slack 频道（[#talent-challenge](https://slack.tidb.io/invite?team=tidb-community&channel=talent-challenge-&ref=github/talent-plan)）进行自我介绍。
2. 导师将与学员沟通其拟参与的项目，并分配编程任务。
3. 学员需在导师指导下完成所选项目的编程任务，并使用 [模板](MENTEE_APPLY_TEMPLATE.md) 将个人简历发送至 [talent-plan@tidb.io](mailto:talent-plan@tidb.io)。
4. 导师将根据学员的人才计划课程成绩、编程任务表现及综合能力，决定是否录取其参与项目。
