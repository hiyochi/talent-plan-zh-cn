# TP 103：构建一个友好的社区

一个友好的社区是对您项目未来和声誉的投资。在友好社区中的人们更有可能使用、贡献并推广您的项目。本课程汇集了一系列与开源社区相关的学习材料，将引导您了解开源项目中的角色、社区治理模式、保持社区活力的技巧，并以 TiDB 的开源实践作为案例进行分析。

***重要提示：*** ***“构建一个友好的社区”目前处于 Alpha 阶段。*** 其范围有限。如果您现在正在学习本课程，您是勇敢的，但同时也是早期测试者，您的反馈将被高度重视。我们鼓励您报告错误、提出修改建议、更新内容等。**更多详情请参阅 [贡献指南](../CONTRIBUTING.md)。**

## 本课程适合谁

开源项目所有者、开源爱好者

## 您将学到什么？

* 开源社区中的角色与组织结构
* 社区治理模型
* 如何保持社区的活力
* 开源社区中的领导力

### 先修要求：

我们建议您先完成 [TP 101：开源软件入门](./tp101-intro-to-oss.md)
